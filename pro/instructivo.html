🚀 Iniciar el Servidor

Desde la carpeta del proyecto

cd "Overlays Facebook"
npm start

Deberías ver: Servidor corriendo en http://localhost:3000

Tip: Dejá la terminal abierta durante toda la transmisión. Si la cerrás, el servidor se detiene.

Verificar que todo funciona

  1. Abrí http://localhost:3000/pro/ en el navegador
  2. El badge en el header debe decir CONECTADO en verde
  3. Si dice "Desconectado", revisá que el servidor esté corriendo

En caso de error de base de datos

El sistema funciona sin PostgreSQL para controles básicos (marcador, timer, alertas). Solo las funciones de "Cargar desde BD" requieren la base de datos activa.

📺 Configurar OBS

Agregar cada overlay como Browser Source

1
En tu escena de OBS → botón + → Navegador (Browser Source)
2
Configurar el browser source con estas opciones:
  • Ancho: 1920
  • Alto: 1080
  • FPS: 30
  • ☑ Actualizar navegador cuando la escena se active
  • Color de fondo: #00000000 (transparente)
3
Repetir para cada overlay deseado. Apilarlos en la misma escena.

⚽ Marcador

Seleccionar equipos

Usá los selectores desplegables para elegir los equipos. Al seleccionar un equipo se carga automáticamente el logo y los colores de camiseta.

Goles

Usá los botones + y − al costado del número. El cambio se refleja en todos los overlays instantáneamente.

Información del partido

  • Torneo: Nombre del torneo (ej: APERTURA 2026)
  • Árbitro: Nombre del árbitro principal
  • Estadio: Nombre del estadio
  • Estado manual: Fuerza el estado del partido (útil para corregir errores)

DT

Ingresá el nombre del director técnico de cada equipo. Se muestra en el overlay de formaciones pre-partido.

Colores de camiseta

Los color pickers controlan el color de la camiseta y los números, usados en el overlay de formaciones para distinguir visualmente cada equipo.

👕 Plantel del Partido

Esta sección permite cargar y editar los jugadores de cada equipo. Los cambios se envían a los overlays cuando presionás "Guardar Plantel en Pantalla".

Cargar desde la base de datos

1
Primero seleccioná el equipo en el selector del Marcador
2
En la sección Plantel, hacé clic en 📥 Cargar de BD
3
Se cargan los jugadores registrados en la base de datos. Asignales el número de camiseta correcto a cada uno
4
Mové jugadores entre Titulares y Suplentes con el botón ↕
5
Presioná 📡 Guardar Plantel en Pantalla para enviar a los overlays

Agregar jugador manual

Usá los campos al pie de la lista para agregar jugadores que no estén en la BD. Ingresá número y nombre, luego clic en + Agregar. Se agrega automáticamente a titulares (si hay menos de 11) o a suplentes.

Controles por jugador

− / +Agregar o quitar goles al jugador
🟨Toggle tarjeta amarilla (opaco = sin tarjeta)
🟥Toggle tarjeta roja (opaco = sin tarjeta)
⭐Marcar como figura del partido

Recordá: Cada vez que hagas cambios en las tarjetas o goles de un jugador, necesitás volver a hacer clic en "Guardar Plantel en Pantalla" para que se reflejen en los overlays.

📋 Incidencias

Registra todas las jugadas importantes del partido. El historial de incidencias se guarda y se usa para los overlays de formaciones (mostrando tarjetas y goles por jugador).

Registrar una incidencia

  1. Seleccioná el Tipo: Gol, Amarilla, Roja, Cambio o VAR
  2. Elegí el Equipo: Local o Visitante
  3. Elegí el Jugador del desplegable (se carga desde el plantel actual)
  4. El Minuto se toma automáticamente del timer. Podés sobreescribirlo
  5. Para cambios: elegí también el jugador que sale
  6. Clic en + Registrar Incidencia

Deshacer

Cada incidencia en la lista tiene un botón ✕ para eliminarla si fue un error.

Atención: Eliminar una incidencia no revierte automáticamente el marcador ni las tarjetas del jugador en el plantel. Hacé los ajustes manualmente.

💰 Publicidad

Tipos de inserción

TipoDescripciónDuración sugerida
📺 BannerBanda inferior animada con nombre y logo del sponsor15-30 segundos
🎬 CortinaPantalla completa con logo grande del sponsor y partículas5-10 segundos
🏷 Overlay MarcaBanner inferior siempre visible (branding permanente)Permanente

Configurar sponsor

  1. Ingresá el Nombre del sponsor
  2. Ingresá la URL del logo (puede ser una ruta local como sponsors/logo.png)
  3. Presioná el tipo de inserción deseado

Publicidad automática

  1. Configurá el intervalo en minutos (ej: cada 10 min)
  2. Clic en Activar Auto
  3. El banner aparecerá automáticamente cada N minutos
  4. El countdown muestra cuándo es la próxima inserción
Flujo de publicidad en entretiempo: Activar Cortina → esperar 8s → Desactivar → Activar tabla de posiciones.

📰 Ticker de Noticias

El ticker es una banda horizontal que scrollea en la parte inferior de la pantalla con textos personalizados.

Agregar items

  1. Escribí el texto en el campo de input
  2. Clic en + o Enter
  3. Los items se agregan a la cola de scroll
  4. Activar el widget Ticker para mostrarlo en pantalla

Para eliminar un item, clic en el ✕ al costado.

Sugerencias de contenido: Resultados de otros partidos, próximo fixture, info del partido, datos del torneo.

📊 Estadísticas en Vivo

Posesión

Deslizá el slider para ajustar el porcentaje de posesión. El porcentaje del otro equipo se ajusta automáticamente para sumar 100%.

Contadores

Usá los botones + y − para cada estadística:

  • Tiros: Total de tiros al arco y afuera
  • Al arco: Tiros que fueron al arco (atajados o goles)
  • Corners: Tiros de esquina
  • Faltas: Faltas cometidas
  • Offsides: Posiciones adelantadas

Jugador Destacado

Seleccioná un jugador del plantel y una descripción de su rendimiento (ej: "2 goles", "5 remates", "90% pases"). Clic en Guardar Destacado.

Se muestra en el panel de estadísticas lateral del overlay.

🗂 Formaciones Pre-Partido

Muestra una pantalla comparativa con los planteles de ambos equipos antes de iniciar el partido.

Configuración

  1. Seleccioná la formación táctica de cada equipo (4-3-3, 4-4-2, etc.)
  2. Asegurate de tener el plantel cargado (sección Plantel del Partido)
  3. Verificá que estén el DT y los colores de camiseta
  4. Clic en Mostrar / Ocultar Overlay Previa

El overlay muestra: escudo, nombre, formación, DT, titulares con número/nombre/posición, suplentes y un campo de fútbol central.

Cuándo mostrar la previa: Mientras se espera el inicio del partido, durante los primeros 15 minutos antes del arranque, o en los minutos previos a la transmisión.

🚨 Modo Emergencia

El botón EMERGENCIA en el header oculta instantáneamente todos los overlays de pantalla.

Cuándo usarlo

  • Error técnico que requiere cortar los gráficos rápidamente
  • Contenido inapropiado en pantalla
  • Falla general del sistema que requiere intervención manual

Cómo desactivar

Aparece una pantalla roja con el botón DESACTIVAR EMERGENCIA. Presionalo para volver a la transmisión normal.

Nota: El modo emergencia oculta los overlays en los browsers conectados, pero no apaga el stream de OBS. Para cortar completamente la transmisión, usá los controles de OBS.

🎬 Flujo de Trabajo Tipo

2 horas antes del partido

1
Iniciá el servidor con npm start
2
Abrí el panel: http://localhost:3000/pro/
3
Configurá OBS con todos los Browser Sources
4
Seleccioná equipos y cargá los planteles desde BD
5
Ajustá números de camiseta, DT y formaciones
6
Configurá datos del partido (torneo, árbitro, estadio)
7
Guardá los planteles en pantalla

30 minutos antes — Pre-partido

1
Activar widget Previa Formaciones → mostrar plantel pre-partido
2
Si hay sponsor: configurar publicidad y activar banner/cortina
3
Activar ticker con info del partido

Al inicio del partido

1
Desactivar Previa Formaciones
2
Activar widget Marcador
3
Seleccionar período 1T y presionar ▶ INICIAR

Durante el partido

  • Goles: registrar incidencia → presionar alerta ⚽ GOL → actualizar marcador con +
  • Tarjetas: registrar incidencia → actualizar plantel con toggle de tarjeta → Guardar
  • Cambios: registrar incidencia tipo Cambio → mover jugador en plantel → Guardar
  • Estadísticas: actualizar contadores de tiros, corners, faltas según el juego

Entretiempo

1
Pausar timer → Seleccionar período ET
2
Activar tabla de posiciones o formaciones
3
Lanzar cortina de sponsor si aplica

Al terminar

1
Seleccionar período FIN → Alerta 🏁 FIN
2
Desactivar marcador
3
Resetear estado para el próximo partido (botón Sistema → Resetear)

💡 Tips y Atajos

Plantillas de transmisión

El selector Plantilla en el header carga automáticamente el nombre del torneo correcto:

  • Liga Regular: LIGA APERTURA 2026
  • Copa / Eliminatoria: COPA REGIONAL 2026
  • Amistoso: PARTIDO AMISTOSO
  • Liguilla Final: LIGUILLA FINAL 2026

Modo sin internet

El panel guarda el último estado en localStorage del navegador. Si el servidor se cae momentáneamente, podés seguir trabajando y los cambios se sincronizarán al reconectar.

Múltiples operadores

Podés abrir el panel en varias computadoras de la red local usando la IP del servidor: http://[IP-DEL-SERVIDOR]:3000/pro/. Todos los cambios se sincronizan en tiempo real.

Historial de acciones

El panel guarda las últimas 30 acciones con timestamp. Útil para verificar cuándo ocurrió cada incidencia o para detectar errores.

El badge de conexión

  • CONECTADO — Todo bien, los overlays reciben actualizaciones
  • DESCONECTADO — Verificar que el servidor esté corriendo

Atajos de teclado recomendados (OBS)

Configurá hotkeys en OBS para activar/desactivar escenas rápidamente mientras operás el panel.

Actualizar la base de datos

Para agregar nuevos jugadores o equipos, usá el Panel Admin Original que tiene las herramientas de gestión de base de datos.
